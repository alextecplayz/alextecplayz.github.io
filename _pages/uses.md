## Software

### Operating Systems

- Android 16, using unofficial port of LineageOS 23.2 with kernel 4.19.325, no GAPPS, no microg. Fully de-googled, fully debloated.
- [Debian](https://debian.org) Trixie/Sid with KDE Plasma, running Wayland. If I were to try a new distro, it would be QubesOS, and on QubesOS I would have Debian VMs.
- [Raspberry Pi OS](https://www.raspberrypi.com/software/) - Debian-based, easy to use if you're familiar with Debian. It's super lightweight as well, my Pi5 4GB uses ~2.5GB to run the OS, Vaultwarden, Radicale WebDAV and Immich.
- [Ubuntu](https://ubuntu.com) - My previous Linux operating system, that I started using two years ago (20.04, was it?), up until 23.10, after which I moved to Debian 13 trixie/sid, because I didn't like the update cycle, so a 'semi-rolling' release would work better for me instead. I like it, but it comes with stuff such as Snap, and some Ubuntu stuff that I don't like. And now that I compare it with Debian, I think Debian might run smoother in some cases, not by much, but there is a slight performance difference.
